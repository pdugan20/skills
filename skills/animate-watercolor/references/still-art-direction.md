# Still-art direction before motion

Read this for a new subject in an existing watercolor family, or when the user
rejects the artwork itself. The deliverable is reviewable art at the intended
quality, not renderer scaffolding that the user must imagine becoming a painting.

## Establish the visual target

Inspect the actual accepted paintings, not just their renderer or documentation.
Use their pixels as style references. Separately inspect the supplied object
photos for physical shape, perspective, material, labels and accessories.
An interactive demo informs behavior; it does not select a different device
generation, material or illustration style.

Identify the handling that must transfer: selective ink and its weight, pigment
edges, wash scale, granulation, white reserves, color density and detail density.
Separate those choices from composition: view angle, orientation, cable footprint,
crop and the intended entrance or placement. Hold the object and style stable
when comparing compositions. Hold composition stable when testing paint handling.

Start with one credible still unless the user has requested a bounded comparison
set. A selected set does not need another approval to make its alternatives.
Use the actual art-creation/editing capability when authorized, with the accepted
paintings attached as visual references. Preserve source, exact prompt and output
provenance. Avoid requiring new tools or services merely to start a study.

## Match the artifact to the decision

| Decision | Useful evidence | Misleading substitute |
| --- | --- | --- |
| Does the new subject belong to the painting family? | Finished still beside accepted art at the same display scale | SVG primitives, angular patches or a noise filter labeled watercolor |
| Which angle or accessory arrangement works? | Credible artwork in each requested arrangement | Crude placeholders whose shape or style dominates the response |
| Does it enter and crop correctly? | Suitable artwork at the actual corner, size and entrance orientation | Cable cut at an internal image box while appearing to stop inside the page |
| Does a display update correctly? | Separate live screen layer aligned with accepted housing | Inventing a painterly shell around working menu code before art acceptance |

SVG and canvas remain useful for authored contours, masks, brush scores and live
overlays after the source is established. They are also valid artwork media when
the user chooses them and their output meets the reference quality. Do not use
them as a covert fallback for an unavailable or unauthorized image tool.

If an arrangement sketch is genuinely needed, identify the narrow question it can
answer before making it. Do not present low-fidelity studies for aesthetic
selection when the user is asking for high-quality painting style. A disclaimer
that texture is provisional does not make an unusable proxy worth reviewing.

## Failure modes from the iPod study

| Visible failure | Cause to check | Correction |
| --- | --- | --- |
| Camouflage or marbled plastic | Angular vector patches plus multiplied all-over grain | Return to the accepted painting references and actual art medium; depict material-specific washes and white reserves, rather than tuning generic noise |
| Product render or beveled card instead of a flat face | Directional gradients, doubled rims, shiny bands and cast shadows invented beyond the reference | Preserve the photographed plane and perspective; distinguish object thickness from painted surface texture |
| Headphones feel toy-like | Generic ovals/stems, compressed cable and arbitrary routing | Use the actual earbud shell, grille, stem and strain relief; show plausible slack or deliberately put headphones beyond the crop |
| Cable hides beyond the wrong edge | Composition drawn without considering entrance and viewport | Trace it toward an edge concealed by the intended placement; a bottom-right entrance may require right or bottom, not left |
| Several variants look equally unhelpful | Small filter or opacity changes within an unsuitable representation | Change the art method or references before asking for another aesthetic decision |
| Crisp screen is treated as finished typography | Convenient fallback font substituted for required device type | Record the required typeface, keep placeholders explicit, and resolve the usable font and live layer after the artwork |

These are diagnostics, not universal bans on gradients, shadows, SVG or texture.
An accepted metal can may have reflective shading; the issue is whether the new
depiction matches its reference and the chosen painting family.

## Judge before asking the user to judge

Review the actual output beside the accepted painting at site size and in both
themes. Check silhouette, landmarks, plane/perspective, accessory anatomy,
contour quality, pigment behavior and retained whites. Inspect the intended crop,
not just a centered gallery cell. A passing compile check cannot establish art
quality, and a screenshot is only evidence of the artifact it shows.

If the result obviously misses, name the miss and correct the source or method
within the authorized batch. Do not ask the user to choose the least bad result
or keep multiplying weak variants. If a new medium or capability needs approval,
state that concrete boundary rather than building another substitute.
When the user says the art is bad, reassess the representation and reference use
before adjusting another shader, filter or opacity value.

After still acceptance, preserve its geometry and style while authoring the
reveal. Keep later screen content, required typography, playback and ambient
effects separable; their feasibility does not justify starting them early.
