Get Acme Sync running in five minutes. The MCP server supports 37 tools for
querying and updating your library.

<Tip>
You can also install with Homebrew if you prefer.
</Tip>

<Note>
Acme Sync needs Python 3.11 or later.
</Note>
<Warning>
Running sync twice concurrently can corrupt the local index.
</Warning>

## Install

```bash
pip install acme-sync
acme-sync init
```

## First sync

```bash
acme-sync run
```
